# VISUAL SIGNAL DROP FOLDER

Upload video files directly into this folder.

Supported extensions: `.mp4`, `.webm`, `.mov`, `.m4v`, `.ogv`.

After an upload commit, the `Update visual signal manifest` workflow rebuilds `manifest.json` and publishes the updated site to `gh-pages`.

For faster loading, keep clips short and compressed. MP4/H.264 or WebM is recommended.
